# Bloque 04

## Resultado
- Qué añadí al proyecto: Añadí las operaciones para gestionar espacios.
- Ruta o pantalla comprobada: Probé listar, consultar, crear, editar y eliminar.
- Estado y respuesta observados: Las operaciones dieron respuestas correctas y se rechazaron datos inválidos.

## Comprensión
- Recorrido del dato, explicado con mis palabras: La petición llega a la API y esta devuelve un resultado.
- Cambio guiado y resultado: Separé las rutas de espacios de las de actuaciones.
- Error encontrado y cómo lo resolví: Corregí las rutas antes de probarlas.

## Evidencias
- Captura o transcripción breve, sin credenciales: Probé las operaciones con curl; falta guardar una captura.
- Limitaciones del ejercicio: Los cambios son de ejemplo y no se conservan.
