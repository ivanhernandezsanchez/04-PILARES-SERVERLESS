# Bloque 03

## Resultado
- Qué añadí al proyecto: Añadí la creación de espacios.
- Ruta o pantalla comprobada: Probé crear un espacio.
- Estado y respuesta observados: Los datos válidos responden 201; los incorrectos, 400.

## Comprensión
- Recorrido del dato, explicado con mis palabras: Envío nombre, capacidad y estado; la API los revisa.
- Cambio guiado y resultado: Usé datos de espacios en vez de actuaciones.
- Error encontrado y cómo lo resolví: La API rechaza datos incompletos o incorrectos.

## Evidencias
- Captura o transcripción breve, sin credenciales: Probé con curl; falta guardar una captura.
- Limitaciones del ejercicio: La respuesta no queda guardada al reiniciar.
